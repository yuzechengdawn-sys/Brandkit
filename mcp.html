MCP 服务

让 AI 根据任务类型读取正确的品牌规则、模板和资产。

安装

将 BrandKit 添加到支持 MCP 的 AI 客户端。

Trae配置
{
  "mcpServers": {
    "brandkit": {
      "url": "<YOUR_BRANDKIT_MCP_URL>",
      "headers": {
        "Authorization": "Bearer <YOUR_TOKEN>"
      }
    }
  }
}

能力清单

一期页面只展示查询与分发逻辑。

get_brand_context(task)

按物料、尺寸和主题返回最小规则包。

get_asset(id, variant)

获取已审核的标识、图形与模板资产。

get_templates(task)

返回当前任务可以使用的品牌模板。

get_rule_version()

读取当前发布版本与更新时间。
